# Низоми имтиҳон: ҷойгиркунӣ дар cPanel

## Талабот

- PHP 8.1 ё навтар бо `PDO MySQL`, `mbstring` ва `sessions`.
- MySQL ё MariaDB.
- SSL/HTTPS барои зердомен.
- cPanel бо `MySQL Database Wizard`, `phpMyAdmin` ва `File Manager` ё FTP.

Суроғаи сайт: `https://kollejimilitsiya.inc`.

## 1. Зердомен ва пойгоҳи дода

1. Дар cPanel домени `kollejimilitsiya.inc`-ро ба Document Root пайваст кунед ва SSL-ро фаъол намоед.
2. Бо MySQL Database Wizard пойгоҳи дода ва корбар созед. Барои корбар ҳамаи ҳуқуқҳои ҳамин пойгоҳи дода заруранд.
3. Дар phpMyAdmin пойгоҳи навро интихоб карда, `schema.sql`-ро ворид кунед. Скрипт гурӯҳи `2-101`, се фан, саволҳои намунавӣ ва се имтиҳони намунавиро месозад. Ҳисоби администратор аз саҳифаи яккарата сохта мешавад.

## 2. Танзими пайваст

Файли `config.php`-ро кушоед ва арзишҳои зерро аз cPanel пур кунед:

- `db_host`: одатан `localhost`.
- `db_name`: номи пурраи пойгоҳи дода бо префикси cPanel.
- `db_user`: номи пурраи корбари MySQL бо префикси cPanel.
- `db_password`: рамзи корбари MySQL.
- `setup_key`: калиди нави тасодуфии 64-рақамаи шонздаҳӣ.

Агар cPanel Terminal дошта бошад, калидро чунин ҳосил кардан мумкин аст:

```sh
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
```

Калиди баромадаро ба `setup_key` гузоред. Рамзи MySQL ва калиди насбро дар чат нафиристед.

## 3. Бор кардани файлҳо

Ба Document Root-и зердомен ин файлҳоро бор кунед:

- `.htaccess`
- `api.php`
- `app.js`
- `config.php`
- `images.jfif`
- `index.html`
- `index.php`
- `setup_admin.php`

`schema.sql`-ро баъди воридот дар Document Root нагузоред; агар бор карда бошед, пок кунед. `.htaccess` `config.php` ва `index.html`-ро аз дархости мустақим маҳкам мекунад. Саҳифаи корӣ тавассути `index.php` хизмат дода мешавад.

## 4. Сохтани администратор

1. Дар браузер `https://kollejimilitsiya.inc/setup_admin.php`-ро кушоед.
2. Калиди насб, номи пурра, логин ва рамзи қавии на кам аз 12 аломатро ворид кунед.
3. Баъди паёми муваффақ, `setup_admin.php`-ро аз Document Root пок кунед.
4. Ба `https://kollejimilitsiya.inc` ворид шуда, бо ҳисоби нав ворид шавед.
5. Администратор гурӯҳ ва донишҷӯёнро созад; баъд фан, савол ва имтиҳонҳоро илова кунад.

Ҳисобҳои намоишии нусхаи маҳаллӣ дар сервер фаъол нестанд. Рамзҳои донишҷӯён танҳо баъди эҷоди ҳисоб аз ҷониби администратор кор мекунанд.
Роҳи `https://kollejimilitsiya.inc/admin` ба портали воридшавӣ мебарад; баъди ворид шудан бо ҳисоби администратор панели идоракунӣ дастрас мешавад. `setup_admin.php` танҳо барои сохтани ҳисоби аввал аст.

## Санҷиши баъди насб

- Саҳифаи асосии зердомен бе хатои PHP кушода мешавад.
- Администратор ворид шуда метавонад; логини нодуруст рад мешавад.
- Администратор гурӯҳ, донишҷӯ, фан, савол ва имтиҳон илова карда метавонад.
- Администратор метавонад донишҷӯро ғайрифаъол кунад; натиҷаҳои пешинаи ӯ дар ведомост мемонанд.
- Гурӯҳ ё фан танҳо вақте нест мешавад, ки дигар ба донишҷӯ, савол ё имтиҳон пайваст набошад.
- Донишҷӯ танҳо имтиҳони гурӯҳи худ мебинад.
- Ҷавобҳои интихобшуда баъди навсозии саҳифа нигоҳ дошта мешаванд.
- Ҳар донишҷӯ барои ҳар имтиҳон танҳо як кӯшиш дорад; баъди анҷоми муваффақ ё тамом шудани вақт оғози дубора рад мешавад.
- Агар вақти имтиҳон гузашта бошад, сервер ҷавобҳои сабтшударо ҳисоб карда, натиҷаро ҳамчун муҳлаттамом нигоҳ медорад.
- Пас аз анҷом, хол дар сервер ҳисоб шуда, дар бахши натиҷаҳои администратор ва донишҷӯ пайдо мешавад.
- Дар `phpMyAdmin` нусхаи эҳтиётии пойгоҳи дода сохта мешавад.

## Маҳдудиятҳои муҳим

- Файлҳои ҳозираи `localStorage` ба MySQL кӯчонида намешаванд; онҳо маълумоти маҳаллии намунавӣ мебошанд.
- Пеш аз истифодаи воқеӣ SSL-ро фаъол ва ҳамаи ҳисобҳои донишҷӯро бо рамзҳои инфиродӣ созед.
- Нусхаи эҳтиётии MySQL-ро мунтазам гиред ва PHP-ро навсозӣ кунед.
- Агар cPanel `Require all denied`-ро дастгирӣ накунад ё `.htaccess`-ро татбиқ накунад, аз дастгирии хостинг хоҳиш кунед, ки дастрасии HTTP ба `config.php` ва файлҳои танзимро маҳкам намоянд.
